# Fury of the Sky

Аркадный воздушный бой для Sony PSP (homebrew). Между War Thunder и Ace Combat: без упора в реализм,
максимально зрелищно в пределах PSP. Целевое железо — PSP-3006 с CFW.

**Сейчас:** M1.5 «Ощущения» — тестовый полёт на Су-35С над морем: модель полёта со сверхманевренностью
(«кобра», «кульбит»), подвижные рули и сопла с ОВТ, форсаж, звуковой барьер, конденсат, ловушки, векторный HUD.
Плюс «Ангар» — просмотрщик модели.

## Быстрый старт (macOS, Apple Silicon)

```bash
tools/install_toolchain.sh     # pspdev в ~/pspdev + первая сборка
tools/smoke_test.sh            # проверка в эмуляторе (нужен: brew install --cask ppsspp)
tools/deploy.sh                # на PSP по USB
```

Управление в полёте: стик — угол атаки/крен, L/R — рыскание, △ — форсаж, ✕ — тормоз, ○ — ПСМ (ограничители
сняты: «кобра» = ○ + стик на себя), □ — ловушки, START — меню, SELECT — скриншот. Подробнее —
[docs/architecture.md](docs/architecture.md#управление-flightscene).
