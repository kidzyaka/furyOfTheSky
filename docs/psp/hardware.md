# Железо PSP: что важно для движка

Пометки: **[док]** — из документации/общеизвестных источников, **[замер]** — измерено нами (с датой),
**[не проверено]** — требует проверки.

## Целевая консоль: PSP-3006

| Параметр | Значение | Источник |
|---|---|---|
| CPU | MIPS32 Allegrex, 1–333 МГц, FPU одинарной точности | [док] |
| Частота по умолчанию | **222 МГц**; поднять до 333: `scePowerSetClockFrequency(333, 333, 166)` | [док] — в коде пока не сделано |
| VFPU | векторный сопроцессор: 128 float-регистров, матрицы 4×4 | [док] |
| ОЗУ | 64 МБ (PSP-1000 — 32 МБ). Пользователю по умолчанию ~24 МБ, с `MEMSIZE=1` на 2000+ больше | [док], объём [не проверено] |
| VRAM (eDRAM GE) | 2 МБ | [док] |
| Экран | 480×272, 16:9, 60 Гц | [док] |
| Кэш текстур GE | 8 КБ | [док] |
| Ввод | крестовина, аналоговый стик (8 бит, люфт центра), △○✕□, L/R, START/SELECT, HOME | [док] |
| Сеть | Wi-Fi 802.11b, ad-hoc (у PSP-E1000 Wi-Fi нет) | [док] |

## Карта VRAM в игре

См. [architecture.md](../architecture.md) → «Память». Свободно ~688 КБ после двух буферов 8888 и глубины.
