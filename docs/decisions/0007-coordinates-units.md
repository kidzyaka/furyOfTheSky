# 0007 — Система координат и единицы

- **Статус:** Принято
- **Дата:** 2026-10-13

## Решение
- **Единица — метр.** Самолёты в реальном масштабе (Су-35С: длина 21,9 м, размах 15,3 м).
- **Игровое пространство (правое):** +X — вправо, +Y — вверх, **−Z — вперёд** (нос самолёта).
  Совпадает с соглашением OpenGL/GU для камеры: `sceGumLookAt` и проекция работают без доп. поворотов.
- **Пространство моделирования (Blender):** +X — правое крыло, +Y — нос, +Z — вверх.
- **Экспорт:** `(x, y, z)_blender → (x, z, −y)_game` — и для позиций, и для нормалей. Это поворот
  (определитель +1), порядок обхода треугольников сохраняется.
- Начало координат модели — примерно центр масс (середина длины по Y_blender).
- Текстурные координаты: v = 0 — первая строка текстуры в памяти (как читает GE). В Blender v направлена
  вверх, поэтому в Blender хранится `1 − v`.

## Последствия
- На больших расстояниях float теряет точность (на 10 км шаг ~1 мм — достаточно). Если карта вырастет
  до сотен км — перейти на камеро-относительные координаты при отрисовке.
