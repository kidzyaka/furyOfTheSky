# 0006 — Формат меша FSM3: индексированный, float

- **Статус:** Принято
- **Дата:** 2026-10-13

## Контекст
С гладкими нормалями вершины разделяются между треугольниками, неиндексированный список раздувается втрое.
Формат должен читаться в память и отдаваться GE без преобразований.

## Решение
- Индексированный список треугольников, индексы **16 бит** (≤ 65535 вершин на меш).
- Вершина 32 байта: `GU_TEXTURE_32BITF | GU_NORMAL_32BITF | GU_VERTEX_32BITF` — u, v, nx, ny, nz, x, y, z.
- Один `sceGumDrawArray` на меш. Заголовок 16 байт → массивы остаются выровнены на 16.
- Спецификация — [formats/fsm3.md](../formats/fsm3.md).

## Рассмотренные альтернативы
- **16-битные компоненты** (`GU_VERTEX_16BIT`, `GU_NORMAL_8BIT`, `GU_TEXTURE_16BIT`, 14 байт/вершина) —
  в 2,3 раза меньше трафика. Отложено до первых замеров производительности на железе:
  float проще отладить, ошибку масштаба в fixed-point без отладчика искать дорого.
- Неиндексированный (FSM1/FSM2) — было в первых итерациях, ×3 по памяти при гладких нормалях.

## Последствия
- Су-35С: 6056 треугольников, 4936 вершин → ~190 КБ.
- Переход на 16-битные компоненты — новая версия формата (FSM4) + матрица масштаба модели.
