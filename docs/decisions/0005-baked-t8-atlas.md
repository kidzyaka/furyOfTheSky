# 0005 — Запечённый текстурный атлас T8 с зеркальной развёрткой

- **Статус:** Принято (заменяет первую итерацию: 16 цветов, планарные проекции по квадрантам)
- **Дата:** 2026-10-13

## Контекст
Первая версия Су-35С (плоское затенение граней, атлас T4 512×512 из 4 планарных проекций, 10,7 текселя/м)
автор оценил как «уровень Роблокса». Нужна правдоподобная окраска: камуфляж, швы, рули, затенение в стыках —
в пределах памяти и пропускной способности PSP.

## Решение
1. **Развёртка:** правая половина модели → Blender `smart_project` (угол 52°) + `pack_islands` (CONCAVE).
   Левая половина — зеркальная копия с теми же UV → удвоение плотности. Результат для Су-35С: **~26 текселей/м**,
   заполнение атласа ~55%.
2. **Раскраска в 3D:** каждый тексель растеризуется обратно в 3D-позицию, нормаль и id части
   (`TexelMaps`). Камуфляж, швы, звёзды, фонарь, сопла задаются функциями от координат в метрах —
   узор не рвётся на швах развёртки, линия флаперона двигается одним числом.
3. **AO:** трассировка лучей по BVH полной (зеркальной) модели, 20 лучей на тексель, 256×256 → апскейл + блюр.
   Сила 0.85. Даёт контактные тени в стыках — главный вклад в «объём».
4. **Формат:** 512×512, **T8** (8 бит, CLUT 256 × ABGR8888). Палитра — k-means по 80k выборок, 14 итераций.
   4 мип-уровня (512→64) с той же палитрой. Каждый уровень swizzled. Размер ≈ 341 КБ.
5. **Ливрея = отдельный файл** `<модель>_<ливрея>.ftx`; меш общий.
6. Дилатация 12 пикселей за край островов — против просвечивания фона на мипах и при билинейке.

## Рассмотренные альтернативы
- **T4 (16 цветов)** — вдвое меньше, но AO/швы/градиенты сжимаются в полосы. Возможен для дальних LOD.
- **RGB565 16 бит** — без квантизации, но 512 КБ на уровень 0 и вдвое больше трафика к GE.
- **Вершинные цвета** — бесплатно по памяти, но камуфляж требует густой сетки, не хватает детализации.
- **Планарные проекции по квадрантам** (v2) — просто, но 10,7 текселя/м и 75% атласа пустые.

## Последствия
- **Асимметричные надписи невозможны** (бортовой номер зеркалится). Решение в будущем — отдельные
  декали-квады поверх модели или неперекрывающиеся UV для носовой части.
- Атлас из основной памяти; при нехватке скорости — перенос в свободные ~688 КБ VRAM.
- Предпросмотр в Blender использует ровно квантованный уровень 0 → что видим в превью, то и на PSP
  (кроме освещения, оно на PSP повершинное).
