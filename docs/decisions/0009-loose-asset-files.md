# 0009 — Ассеты отдельными файлами рядом с EBOOT

- **Статус:** Принято
- **Дата:** 2026-10-13

## Решение
- Ассеты лежат обычными файлами в `PSP/GAME/FuryOfTheSky/assets/...` и читаются по **относительным** путям
  (`assets/models/su35s.fsm`). Рабочая папка процесса = папка EBOOT (её выставляет pspsdk при старте).
- Генерированные файлы хранятся в репозитории в `assets/` (собираются из `tools/`), в папку для карты
  памяти копируются при сборке.

## Рассмотренные альтернативы
- Встраивать в EBOOT (заголовки/`.incbin`) — не нужно перезаливать ассеты отдельно, но растёт EBOOT,
  всё сидит в памяти постоянно, нельзя подгружать по уровням.
- Пак-файл (свой архив) — понадобится позже ради скорости открытия файлов на Memory Stick; тогда — новый ADR.

## Последствия
- В PPSSPP, если запустить EBOOT не из «карты памяти» эмулятора, рабочая папка — `umd0:` (только чтение):
  скриншоты не пишутся. smoke-тест поэтому кладёт сборку в `~/.config/ppsspp/PSP/GAME/`.
