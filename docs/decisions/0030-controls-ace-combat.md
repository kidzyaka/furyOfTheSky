# 0030 — Управление v2: раскладка Ace Combat X, ПСМ «как в AC7»

- **Статус:** Принято (заменяет кнопки из [0014](0014-flight-model-v2-psm.md) — ПСМ на ○ — и
  [0010](0010-arcade-flight-model.md) — тяга на △/✕; ловушки на □ из [0017](0017-countermeasures.md) в силе)
- **Дата:** 2026-10-14

## Контекст
С оружием понадобилось ещё четыре действия:
- пушка (держать);
- ракета (нажатие);
- смена цели;
- смена ракеты.

Свободных кнопок под правым большим пальцем не было:
- △ — тяга, ✕ — тормоз;
- ○ — ПСМ, □ — ловушки;
- L/R — рыскание.

С прошлого раза был открыт вопрос автора: ПСМ на ○ или автоматически, как в AC7.

## Решение
Раскладка «Normal A» из Ace Combat X: Skies of Deception (PSP). Её ждут игроки Ace Combat: ✕ пушка, ○ ракета,
△ цель, газ и тормоз на шифтах, рыскание на крестовине.

| Ввод | Действие |
|---|---|
| Стик | тангаж / крен (инверсия тангажа — в меню) |
| R держать | полная тяга → форсаж |
| L держать | малый газ + тормоз (рули направления разводятся) |
| **L + стик до упора на себя** | **ПСМ** ниже 650 км/ч (кобра, кульбит), выше — снятие ограничения 11g → 13g |
| ← / → | рыскание |
| ✕ держать | пушка |
| ○ | пуск ракеты (одна на нажатие) |
| △ | следующая цель |
| SELECT | смена ракеты Р-73 ↔ Р-77 (в PS2-играх Ace Combat переключатель тоже на SELECT) |
| □ держать | ловушки (как было) |
| ↑ | скриншот (был на SELECT) |
| START | пауза |

- **ПСМ — как в Ace Combat 7: «тормоз + ручка на себя».**
  - Пока ПСМ включена, тормоз и малый газ снимаются: модель полёта держит двигатели на максимале, соплам нужна
    тяга (`mapInput`).
  - На большой скорости тот же жест снимает ограничение перегрузки — аналог «High-G turn» из AC7.
- **Порог 0,85 хода стика:** обычное торможение с умеренным взятием ручки не превращается в кобру.
- **Ловушки остались на □:** их отстреливают в оборонительном манёвре, и палец со стика снимать нельзя. Смена
  ракеты — редкое действие, ей хватит SELECT.
- В ангаре кнопки прежние (△ ливрея, ✕ вращение, □ демонстрация рулей).

## Рассмотренные альтернативы
- **ПСМ на ○ (как было).** Тогда ракета уходит на □, а ловушки — на крестовину. Ловушки под левым пальцем — это
  потеря управления в обороне.
- **Ловушки на L+R.** Мгновенно сбрасывает газ и тормоз, мешает в манёвре.
- **Оставить △/✕ под газ.** Тогда пушка и ракета — на шифтах, против всех привычек Ace Combat.

## Последствия
- **Автору придётся переучиться.** Подсказка — внизу меню паузы.
- Мнение автора о ПСМ «как в AC7» **не получено**. Если неудобно, вернуть ПСМ на отдельную кнопку можно правкой одной
  функции `FlightScene::mapInput`.
- Удобство рыскания на крестовине на PSP-3006 **не проверено**: в ACX оно было там же.
