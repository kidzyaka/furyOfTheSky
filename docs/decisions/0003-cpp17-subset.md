# 0003 — C++17 без исключений и RTTI

- **Статус:** Принято
- **Дата:** 2026-10-13

## Контекст
Автор выбрал C++. На PSP 333 МГц CPU и ограниченная память; размер кода и предсказуемость важнее удобства.

## Решение
- Стандарт **C++17**.
- `-fno-exceptions -fno-rtti -fno-threadsafe-statics`.
- Без тяжёлой части STL в горячем коде (никаких `std::vector`-аллокаций в кадре, `std::string`, iostream).
  Допустимы `<cstdint>`, `<cmath>`, `<cstring>`, `<cstdio>`, алгоритмы без аллокаций.
- Ошибки — через `bool`/коды возврата; ресурсы — RAII (пример: `core::Blob`).
- Память: загрузка целиком в выровненные блоки, позже — пулы объектов фиксированного размера.

## Рассмотренные альтернативы
- C — проще ABI, но неудобно описывать сущности игры.
- Полный C++ с исключениями — раздувает бинарник, unwind-таблицы, непредсказуемость.

## Последствия
- `new` без исключений вызывает `abort` при нехватке памяти — критичные аллокации делать при загрузке, не в кадре.
- `-fno-threadsafe-statics`: локальные `static` не защищены от гонок — инициализировать их только из главного потока.
