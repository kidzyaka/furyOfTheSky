# 0002 — Целевое железо: PSP-3006, эмулятор только для smoke-тестов

- **Статус:** Принято
- **Дата:** 2026-10-13

## Контекст
У автора есть физическая PSP-3006 (серия 3000: 64 МБ ОЗУ, Wi-Fi, PAL-регион). Эмулятор ему для игры не нужен.
Но у агента-разработчика нет доступа к экрану PSP, а цикл «скопировал на карту → проверил» медленный.

## Решение
- **Эталон — реальная PSP.** Всё, что не проверено на железе, считается непроверенным.
- **PPSSPP — внутренний инструмент разработчика**, не платформа: smoke-тест перед каждой отдачей сборки
  (`tools/smoke_test.sh`), чтение логов загрузчика/HLE, скриншоты через software renderer.
- Ориентируемся на возможности серии 2000/3000 (64 МБ), но не используем ничего, что сломает PSP-1000,
  без отдельного решения.

## Рассмотренные альтернативы
- Разработка только под эмулятор — PPSSPP прощает ошибки, которые на железе дают зависание
  (кэш данных, выравнивание, тайминги GE).
- Только железо — слишком медленная обратная связь и нет логов.

## Последствия
- Каждую сборку перед передачей автору гоняем в эмуляторе; финальная приёмка — фото/скриншоты с PSP.
- Нужна CFW на консоли (ARK-4 / PRO-C / LME на 6.61).
- Следующий шаг по отладке на железе — PSPLink (printf и исключения по USB), когда понадобится.
