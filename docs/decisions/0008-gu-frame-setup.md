# 0008 — Настройка GU и кадра

- **Статус:** Принято; пункт об отсечении граней заменён [ADR 0012](0012-backface-culling-ccw.md)
- **Дата:** 2026-10-13

## Решение
- Двойная буферизация, оба буфера **8888** (32 бит), stride 512, 480×272. Глубина 16 бит.
  Раскладка VRAM — [architecture.md](../architecture.md) → «Память».
- **Обратная глубина:** `sceGuDepthRange(65535, 0)`, `GU_GEQUAL`, очистка глубины в 0 — стандартная схема PSP.
- `sceGuOffset(2048 − 240, 2048 − 136)` + `sceGuViewport(2048, 2048, 480, 272)` — экран в центре виртуального
  пространства GE 4096×4096.
- **Отсечение задних граней выключено** до проверки порядка обхода на железе (тест глубины даёт верную картинку,
  6 тыс. треугольников это позволяет).
- Один статический список команд 1 МБ, режим `GU_DIRECT`, CPU ждёт GE (`sceGuSync`) каждый кадр.
- Освещение: 1 направленный свет (солнце, мир), `GU_DIFFUSE_AND_SPECULAR`, `GU_SEPARATE_SPECULAR_COLOR`,
  specular power 14, ambient голубоватый. Материал белый (`sceGuColor`), цвет из текстуры (`GU_TFX_MODULATE`).
- Отладочный текст — `pspDebugScreen` поверх готового кадра после `sceGuSync` (overlay в `endFrame`).

## Рассмотренные альтернативы
- 16-битные кадровые буферы (5650) — экономят 544 КБ VRAM, но дают бандинг на градиентах неба. Вернуться,
  если понадобится VRAM под текстуры.
- Двойной список команд (CPU и GE параллельно) — отложено до замеров.
