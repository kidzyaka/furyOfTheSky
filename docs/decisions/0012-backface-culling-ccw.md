# 0012 — Отсечение задних граней: GU_CCW

- **Статус:** Принято (заменяет пункт «отсечение выключено» из [ADR 0008](0008-gu-frame-setup.md))
- **Дата:** 2026-10-13

## Контекст
В ADR 0008 отсечение было выключено «до проверки на железе». Половина треугольников самолёта (и океана) —
задние грани, растеризовать их незачем.

## Решение
- `sceGuFrontFace(GU_CCW)` + `sceGuEnable(GU_CULL_FACE)` глобально (`gu_context.cpp`).
- Меши — правосторонние, обход против часовой стрелки снаружи (так пишет Blender; экспорт в игровые координаты —
  поворот, обход сохраняется). Океан тоже CCW, если смотреть сверху.
- Явно **без отсечения**: 2D-градиент (`GU_TRIANGLE_STRIP` чередует обход) и купол неба (виден изнутри).

## Как проверено
PPSSPP, software renderer (эмулирует логику GE), smoke-тест в двух вариантах:
- `GU_CCW`: самолёт идентичен кадру без отсечения → ни один лофт не вывернут; океан на месте.
- `GU_CW`: самолёт «наизнанку» (видны внутренние грани), океан пропал.
На железе — ожидает проверки.

## Последствия
- Вывернутая деталь в будущей модели станет «дырой» — заметно сразу в превью smoke-теста.
- Новые 2D/внутренние геометрии — помнить про `GU_CULL_FACE`.
