# 0004 — Процедурные модели в Blender, описанные кодом

- **Статус:** Принято
- **Дата:** 2026-10-13

## Контекст
Модели самолётов делаем вместе с автором, по фото-референсам. Нужны: быстрые итерации по замечаниям,
воспроизводимость, контроль бюджета полигонов под PSP, без ручной работы в редакторе.

## Решение
- Каждый самолёт — Python-модуль `tools/models/<имя>.py`, запускаемый Blender в фоне
  (`Blender -b --python tools/models/build.py -- <имя>`). Общий инструментарий — `tools/models/fmodel.py`.
- Геометрия — **лофт через сечения**: фюзеляж и гондолы — суперэллипсы (`se_ring`), фонарь и гаргрот — дуги
  (`arc_ring`), несущие поверхности — профиль NACA 00xx со скруглённым носком (`wing_rings`, `fin_rings`).
  Станции сечений сглаживаются сплайном Catmull-Rom (`spline`).
- Каждый лофт — замкнутая оболочка; нормали наружу через `recalc_face_normals`.
- Парные части (крылья, кили, гондолы) моделируются только справа; модель режется по x=0 и зеркалится.
- Гладкие нормали с **углом излома на группу сглаживания**: каждая сторона лофта и каждая заглушка —
  своя группа; у крыльев угол 110° (носок гладкий, задняя кромка острая), у фюзеляжа 65°.
- Станции измеряем по фото-референсам в плане и сбоку (масштаб ≈ 23 px/м по длине 21,9 м).
- Сборка выдаёт превью (`build/previews/`), их показываем автору до того, как модель считается готовой.

## Рассмотренные альтернативы
- Ручное моделирование в Blender — медленные итерации, не воспроизводится агентом.
- Готовые модели из интернета — лицензии, чужой бюджет полигонов, нет стиля.

## Последствия
- Правка = изменение чисел в коде, полная пересборка ~3 с.
- Части пересекаются, а не сшиваются: невидимые грани внутри (тратят текстуру и треугольники, ~10–15%).
- Асимметричные детали (бортовой номер, смещённая вправо OLS) при зеркалировании дублируются — см. ADR 0005.
