# Р-73 (РВВ-МД, AA-11 «Archer»)

Код: `tools/models/r73.py`. Ассеты: `assets/models/r73.fsm`, `r73_std.ftx`.
Роль: ракета ближнего боя с ИК ГСН; на Су-35С — законцовки крыла и внешние подкрыльевые точки
(см. [su35s.md](su35s.md), «Подвеска»).

## Геометрия модели
Начало координат — **середина длины на оси** (точка подвеса станции = центр ракеты), нос к −Z игры.
Расстояния `d` — от носа.

| Элемент | d, м | Радиус / размах | Примечание |
|---|---|---|---|
| ИК-купол | 0 … 0,062 | полусфера r 0,06 | |
| Кольцо дестабилизаторов | 0,062 … 0,14 | r 0,063 | |
| Конус к полному диаметру | 0,14 … 0,26 | r 0,085 | |
| Дестабилизаторы ×4 | корень 0,074 … 0,14, вершина ~0,13 | размах 0,25 | треугольные, острая вершина |
| Рули ×4 | корень 0,28 … 0,54, конец 0,45 … 0,54 | размах 0,39 | трапеция, ПК ≈ 58°, задняя кромка прямая |
| Крылья ×4 | корень 2,20 … 2,785, конец 2,43 … 2,765 | размах 0,51 | элерон — задние 30 % хорды на внешней половине (нарисован) |
| Сопловой отсек | 2,80 … 2,90 | r 0,085 → 0,071 | срез сопла — тёмный торец |

**Схема оперения — «×»** (плоскости под ±45° к вертикали), все три ряда в одних плоскостях. Так ракета висит на
П-72-1/АПУ-73 и на законцовке Су-27/35 [4], [6]: пусковая проходит между двумя верхними плоскостями.
Профиль плоскостей — ромб (гребень на 40 % хорды), плоское затенение; корень утоплен в корпус без торца.

## Бюджет
| Метрика | Значение |
|---|---|
| Треугольники | 310 (корпус 190 + 12 плоскостей по 10) |
| Вершины | 459 |
| Меш | 16 640 байт (FSM4, одна неподвижная часть) |
| Текстура | T8 128×128, 4 мипа (128…16) — 22 800 байт |
| Плотность текстуры | ~85 текселей/м (≈1,2 см), покрытие атласа 52 % |

Почему 128²: ракета на экране PSP — десятки пикселей даже вблизи, деталь окраски — кольцевые швы, купол, окна
взрывателя, надписи. 256² дало бы 2,9 раза больше текселей без видимой разницы на 480×272.

### Что сделано для маленького атласа (общий код `tools/models/fmodel.py`, `build.py`)
- `TEX` модели задаёт размер атласа (`TEX = 128` в `r73.py`; по умолчанию 512 — Су-35С собирается байт в байт как раньше).
- Корпус разрезан посередине (`revolve(..., breaks=...)`, кольцо удвоено без сварки): два острова по 1,45 м вместо
  полосы 2,9 м — покрытие атласа 22 % → 52 %, плотность 56 → 85 текс/м. Цена — одно кольцо (24 треугольника);
  шов на прямом цилиндре не виден: нормали с обеих сторон радиальные.
- Острова упаковываются без поворота на произвольный угол (`UV_ROTATE = "AXIS_ALIGNED"`): по диагонали швы
  «лесенкой».
- Отступ между островами ≥ 1,5 текселя при любом `TEX`; AO при `TEX` < 512 считается в полном разрешении и
  размывается только внутри атласа (половинное разрешение смешивало соседние острова — чёрные полосы вдоль корпуса).
- `AO_DISTANCE = 0.5` м: масштаб затенения ракеты, а не планера (по умолчанию 2,2 м).

## Ливрея
| Имя | Описание |
|---|---|
| `std` | серийная ВКС: светло-серый корпус и оперение, тёмный купол с отражением неба, светлее — кольцо дестабилизаторов, тёмный металл соплового отсека |

Детали текстуры: швы отсеков (купол, кольцо, конус, отсеки рулей/взрывателя/БЧ/двигателя), пара окон оптического
взрывателя, 3 бугеля сверху, «надписи» на двигательном отсеке, линии элеронов на крыльях, AO.

## Упрощения
- Датчики угла атаки, приёмники ПВД, кожух кабеля вдоль корпуса, бугели — только краской.
- Газовые рули в сопле и роллероны не моделировались.
- Дестабилизаторы — треугольники; на фото у основания они почти прямоугольные (на размере 6 см не различить).

## Открытые вопросы
- Боевая маркировка ВКС (цветные пояски БЧ/двигателя) — по фото не установлена, пояски не рисовались.
- Р-73М/Р-74М (другие рули) — не делались.
