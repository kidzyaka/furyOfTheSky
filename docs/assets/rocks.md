# Скалы и острова Северного моря

Генератор: `tools/models/rocks.py` (Blender, ~45 с на всё, превью в `build/previews/rock_<имя>_{side,high,north,low}.png`).
Решения: [ADR 0042](../decisions/0042-sea-stacks-terrain.md), формат меша — [FTR2](../formats/ftr2.md) (16-битные вершины, свет запечён, [ADR 0051](../decisions/0051-terrain-compact-baked-vertices.md)).

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python tools/models/rocks.py
# только некоторые формы (таблицы столкновений пишутся всегда): -- --only conachair,boreray
# без превью: -- --no-preview
```

Выход:
- `assets/models/rock_<имя>.ftr` — меши;
- `rock_<кекур>.ftx` — кожи кекуров;
- `terrain_cliff.ftx`, `terrain_turf.ftx` — тайлы деталей массивов;
- `src/world/rock_shapes.{h,cpp}` — таблицы столкновений и сетка колонн, руками не править.

## Бюджет

| Форма | Треугольники, полная / самый грубый корень | Кусков | Файл |
|---|---|---|---|
| массивы большие | 37–41 тыс. / ~100 на зону | 188–198 | 1,6–1,7 МБ |
| boreray | 24 тыс. | 112 | 1,0 МБ |
| holm, dun | 13–14 тыс. | ~82 | 0,6 МБ |
| кекуры | 576–3408 / ¼ плотности | 3 | 38–177 КБ |

В кадре:
- у острова на средней дистанции — 2–6 тыс. треугольников;
- в Проливе — ~6,5 тыс.;
- вплотную у 400-метрового обрыва — ~15 тыс., индексов ~16 тыс. (эмулятор, счётчик `T/V`).

На железе не измерено.

## Текстуры
- **Кекуры:** своя кожа 256²–512² (стены — азимут × высота, макушка — квадрат справа). Пласты своих оттенков,
  потёки, базальтовый цоколь, гуано с потёками, ксантория, лишайник, приливная полоса, дёрн. AO запечён.
- **Массивы:** цвет в вершинах (порода по геологии, полки, птичьи базары, верещатник, папоротник, морской луг,
  AO) × тайл деталей.
  - `terrain_cliff` — 40 м: пласты с выклиниванием, наклонные трещины, блоки, потёки;
  - `terrain_turf` — 48 м: кочки, торф, камни.

  Среднее тайлов 0,82, вершинный цвет делится на него.

## Открытые вопросы
- Арки и сквозные пещеры (форма «звёздная» — не умеет).
- Кекуры — списком треугольников, не лентами (нормали с изломом дробят вершины). На дальних уровнях это мелочь,
  вблизи — 3 индекса на треугольник.
- 16-битные вершины для экономии ~45 % памяти рельефа.
- Птицы над базарами, дымка прибоя у подножий — эффектов нет.
