# Дорожная карта

Концепция: аркадный воздушный бой между War Thunder и Ace Combat — без упора в реализм, максимально
зрелищно в пределах PSP. Три эпохи (Вторая мировая, современность, будущее); **сейчас только современность**.

## M0 — «Ангар» (ждёт подтверждения на железе)
Цель: доказать цепочку тулчейн → GU → ассеты → железо.
- [x] Тулчейн, CMake, EBOOT, деплой на PSP
- [x] Генератор моделей + запекание текстур, Су-35С v3, две ливреи
- [x] Просмотрщик: орбитальная камера, освещение, смена ливреи, скриншоты
- [x] Smoke-тест в эмуляторе
- [x] **Запуск на PSP-3006** — подтверждён (исправление импортов ядра работает)
- [x] Отсечение задних граней (`GU_CCW`, проверено в эмуляторе) — ADR 0012
- [x] Частота CPU 333 МГц при старте
- [ ] Замер FPS на железе
