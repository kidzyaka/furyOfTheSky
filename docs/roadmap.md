# Дорожная карта

Концепция: аркадный воздушный бой между War Thunder и Ace Combat — без упора в реализм, максимально
зрелищно в пределах PSP. Три эпохи (Вторая мировая, современность, будущее); **сейчас только современность**.

## M0 — «Ангар» (ждёт подтверждения на железе)
Цель: доказать цепочку тулчейн → GU → ассеты → железо.
- [x] Тулчейн, CMake, EBOOT, деплой на PSP
- [x] Генератор моделей + запекание текстур, Су-35С v3, две ливреи
- [x] Просмотрщик: орбитальная камера, освещение, смена ливреи, скриншоты
- [x] Smoke-тест в эмуляторе
- [ ] **Запуск на PSP-3006** (после исправления импортов ядра)
- [x] Отсечение задних граней (`GU_CCW`, проверено в эмуляторе) — ADR 0012
- [x] Частота CPU 333 МГц при старте
- [ ] Замер FPS на железе

## M1 — Полёт (тестовая сцена готова, ждёт проверки на железе)
- [x] Аркадная модель полёта: энергия, перегрузка, сваливание, форсаж/тормоз — ADR 0010
- [x] Host-тесты физики (11 проверок, детерминизм)
- [x] Камера «на поводке» с инерцией и расширением FOV на скорости
- [x] Мир: купол неба + солнце, бесконечный океан, поле облаков, дымка — ADR 0011
- [x] Меню паузы (сцена, ливрея, инверсия тангажа, рестарт), HUD-текст
- [ ] Настройка ощущений на PSP-3006 вместе с автором (чувствительность стика, скорости, камера)
- [ ] Проверить океан на малой высоте (ближняя плоскость, gotchas №19)
- [ ] Суша: острова/побережье — ориентиры для высоты и скорости у земли
- [ ] Форсажное пламя, инверсионные следы (частично M3)

## M2 — Бой
Пушка, ракеты с захватом цели, 1–2 типа противников с простым ИИ, попадания, взрывы, HUD (прицел,
захват, высота, скорость, боезапас).

## M3 — Зрелищность
Инверсионные следы, дым ракет, форсаж, тряска камеры, отражение на фонаре, LOD самолётов.
